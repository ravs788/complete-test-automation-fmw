# Framework Examples

This directory contains example tests demonstrating various features of the test automation framework.

## UI Examples
- **SauceDemoTests**: Demonstrates end-to-end UI flow testing using Selenium and NUnit.
- **Other UI Tests**: Additional UI test examples showcasing different scenarios.

## API Examples
- **RestfulBookerTests**: Shows how to test REST APIs using RestSharp and NUnit.
- **Other API Tests**: More API test examples covering various API testing scenarios.

Each example is designed to illustrate idiomatic usage of the framework.
